# 版本记录

## 0.1.4 · 2026-10-15

- 更新本轮 7 款现售型号的报价，新增 004 优质 Fast、004 Seedance 2.5、004 Wan 3.0，共 115 款可选视频型号；两款 Native 已隐藏的 006 型号不再列入新版可选目录，历史任务查询保留。
- 三款新品开放文生、图片参考、图片＋音频参考；参数按各型号列出的分辨率、时长、图片和音频数量校验，未知的视频参考等能力暂不开放。
- Wan 3.0 正确显示其系列及阿里巴巴厂商，不再标成 Seedance / 火山方舟；增加其他视频系列筛选。
- 保留原任务历史格式、密钥隔离、防重复提交和未知结果不重发；程序仍需手动下载升级，目录同步不等于自动安装新程序。

## 0.1.3 · 2026-10-11

- 补发含最新 114 款算力 AI Seedance 型号的 Windows x64 便携包，目录版本 `20261010-suanli-update-v1`。相对 0.1.2 的初始 110 款目录，本批新增 13 款、暂停 9 款、调整 3 款价格，并收紧 mini2 至 5–10 秒。
- 调用协议、动态目录同步、提交前价格校验和本地任务历史格式不变；继续按当前型号精确限制参考素材和参数。
- 补充 GitHub Releases 手动下载、SHA256 校验与安全升级说明。程序更新不会自动安装；模型目录仍在连接、刷新和提交前同步。
- 保留旧版与已有任务；更新前需从旧客户端点击「退出」，不能仅关闭浏览器页面。
