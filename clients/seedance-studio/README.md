# CanvasPro 视频工作室 · Windows 便携版 0.1.4

1. 将整个压缩包解压到一个文件夹，不要在压缩包内直接运行。
2. 双击「CanvasPro 视频工作室.exe」。界面在默认浏览器中打开，程序只监听本机地址。
3. 填入 **api.canvasproai.com 的 New API 密钥**，点击「连接并同步模型」。不需要填写上游密钥。
4. 选择模型、清晰度、时长、比例和参考方式，加入素材、填写提示词。
5. 点击「生成视频」，核对预计费用后确认。任务自动查询，完成后直接预览或下载。

升级到 0.1.4 前请点击旧版右上角「退出」，再将新包完整解压到一个新文件夹并启动；不要直接覆盖正在运行的旧目录。只关闭旧浏览器页面不等于退出程序。无需删除旧版或历史文件，历史任务仍可在连接同一密钥后查询。当前版本显示在窗口标题及右上角「本地运行」旁，应为 0.1.4。

后续程序更新从[GitHub 最新版下载页](https://github.com/Namm-star/CanvasPro-Seedance-Studio/releases/latest)下载 `CanvasPro-Seedance-Studio-版本号-windows-x64.zip`，不是 GitHub 自动生成的 `Source code` 压缩包。下载后可用 PowerShell 的 `Get-FileHash -Algorithm SHA256 -LiteralPath '压缩包路径'` 核对发布页提供的 SHA256。客户端不会自动下载或安装程序更新。

## 参数与素材

仅显示对应型号已经开放的参数。清晰度与时长联动，参考图片/视频/音频数量及组合分别限制。修改时长、清晰度或型号会保留兼容素材；只有确实不兼容时，说明将移除的素材并由你确认，取消调整保留原草稿。部分型号音频只接受本地 MP3，并且必须同时有图片参考。

模型列表支持按系列、清晰度、时长、参考方式和计费方式组合筛选，条件必须在同一合法参数档位同时满足。筛选仅查找型号，不会改变当前创作草稿；“清除筛选”可返回全部型号。

可直接选择电脑里的 PNG、JPEG、WebP 图片、MP4 视频和该型号支持的音频。便携版为了控制本机内存和编码体积，本地文件合计上限 **12 MiB**，不是上游单文件的理论上限；较大素材可用公网链接。当前客户端不连接 HC 专用临时图床，也没有上游/R2凭据。未开放的参数（例如自动时长、音频生成开关）不会出现。

模型目录与价格每次连接/刷新、提交前重新核对。价格或参数目录不匹配、Key无权限、型号下架时禁止新提交。显示的是标准组预计积分；提交时以本站有效分组、余额和最终账务记录为准。按秒型号按所选请求时长计费，明确的视频参考倍率型号才应用1.75倍。

0.1.4 内置本轮 115 款视频目录，包含 004 优质 Fast、004 Seedance 2.5 和 004 Wan 3.0，并同步 7 款现售价格；两款已在 Native 隐藏的 006 型号不再列入可选目录，历史任务仍可查询。三款新品先开放文生、图片参考、图片＋音频参考；参考视频及未明确的其他能力暂不开放，不代表上游不支持。Wan 3.0 显示为阿里巴巴模型经合作线路提供，不是 Seedance，也非官方直连。mini2 仍仅允许 5–10 秒。

旧包保持各自原始内置目录，不被改写；可以连接/刷新取得当前目录，但 Wan 系列的正确分类和厂商显示需升级到 0.1.4。模型目录刷新与程序版本更新是两回事：按次/按秒单位、时长和素材组合以同步结果为准；程序不会自动安装更新。目录不兼容时会禁止新提交，不猜参数或自动重发。若密钥限制了模型，需要在本站密钥设置中允许新增型号。

## 任务和结果

每次确认对应一次提交，正在提交时按钮禁用并显示反馈。网络中断或没有返回任务号时，不会自动重发、换模型或自动退款；先在本站任务/用量记录核对。人工核对按钮仅解除客户端新建任务的拦截，不执行退款或重试。

任务号与基本参数保存在 `%LOCALAPPDATA%\CanvasProSeedanceStudio\history.json`，不保存密钥、提示词和素材。重新打开后连接同一密钥，可继续查询原任务。暂停查询或退出客户端 **不会取消上游任务**。生成失败请查本站用量记录，以实际结算为准。

排队或生成中显示累计等待时间、上次成功查询时间和查询连接异常。网络异常不等于生成失败，界面保留上次任务状态；“重新查询原任务”只查同一任务，不会重新生成或再创建付费请求。

密钥只保存在运行内存中，断开或退出后移除。窗口右上角「退出」可结束程序；只关闭浏览器时，本地服务在无访问10分钟后退出。不要把密钥发给他人。客户端只调用本站固定 HTTPS 域名，不向结果链接或外部域名转发密钥。

本版适用 Windows 10/11 x64，内置 Node.js 运行时，无需另装 Node/Python。运行时采用 Node.js 官方发行版，许可证与依赖声明见 `runtime/LICENSE`；客户端源码随包保留。当前启动器未做商业代码签名，下载后 Windows 可能提示发行者未知；请核对发布来源及SHA256，不要关闭系统安全防护。
